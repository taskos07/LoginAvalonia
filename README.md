
Avalonia UI Cross-Platform Login

Un'applicazione cross-platform minimale sviluppata con Avalonia UI che dimostra la gestione dinamica degli stati (Login/Logout) tramite pattern MVVM.

🔄 Logica degli Stati


Stato Corrente	Testo Pulsante	Azione al Clic	Messaggio Visualizzato
Disconnesso	LOGIN	Effettua l'accesso	"Benvenuto/a [Nome]"
Connesso	LOGOUT	Resetta l'interfaccia	"Arrivederci"
